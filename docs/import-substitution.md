# Импортозамещение

## 1. Языковые модели

Ключевое требование: данные не покидают контур. Модель развёрнута локально
(vLLM, открытые веса), а обращение к адресу вне контура отвергается перед
каждым сетевым вызовом (`packages/ml/app/llm.py`). Сеть, в которой работает модель,
объявлена в docker compose как `internal` — выхода наружу у неё нет.

| Компонент | Решение | Лицензия |
|---|---|---|
| Языковая и визуальная модель | Qwen2.5-VL-7B-Instruct, открытые веса, локально | Apache-2.0 (сверить с карточкой модели при скачивании) |
| Сервер модели | vLLM, Chat Completions-совместимый API | Apache-2.0 |
| Распознавание сканов | Tesseract OCR | Apache-2.0 |
| Семантические якоря | paraphrase-multilingual-MiniLM-L12-v2 в ONNX Runtime | Apache-2.0, MIT |

Модель меняется переменными окружения без пересборки кода. Замена на модель
отечественного разработчика с открытыми весами — та же правка окружения, если
её лицензия допускает государственное использование.

## 2. Программная платформа

| Слой | Решение | Замещение |
|---|---|---|
| Операционная система | Linux на стенде; образы на Debian bookworm | Совместимо с Astra Linux SE |
| База данных | SQLite с шифрованием SQLCipher (better-sqlite3-multiple-ciphers) | Встроенная, свободное ПО (MIT) |
| Очередь сообщений | RabbitMQ | MPL-2.0, свободное ПО |
| Кэш | Redis 7.2 | BSD-3-Clause (последняя ветка под BSD); совместимая замена — Valkey (BSD) |
| Сервер | Node.js 22, Fastify 5, TypeScript | Свободное ПО (MIT) |
| ML-модули | Python 3.12 | Свободное ПО |
| Антивирус | ClamAV | GPL-2.0; заменяется антивирусом заказчика с протоколом clamd |
| Мониторинг и логи | Prometheus, Grafana, Alertmanager; Elasticsearch, Logstash, Kibana | Apache-2.0, AGPL-3.0, Elastic License — используются как внешние сервисы контура, замещаются системами заказчика |
| Веб-сервер интерфейса | nginx | Свободное ПО, есть отечественные сборки (Angie) |
| Оркестрация | Docker Compose | Свободное ПО |

Проприетарных компонентов с зарубежной лицензионной привязкой в составе нет.

## 3. Криптография

Собственная криптография не разрабатывается: шифрование базы — SQLCipher,
хранилища и кэша — AES-256-GCM стандартных библиотек (Node.js crypto,
Python cryptography), канал — TLS 1.3. Криптография по ГОСТ — средствами
СКЗИ контура заказчика. Проверка электронной подписи
выполняется средствами контура заказчика; модуль сохраняет только её
результат из реестра (`signature_status`).

## 4. Библиотеки обработки документов

| Библиотека | Лицензия | Назначение |
|---|---|---|
| PyMuPDF | AGPL-3.0 / коммерческая | Разбор PDF, отрисовка листов |
| reportlab | BSD | Приведение DOCX и XML к PDF |
| python-docx | MIT | Приём DOCX |
| pdfkit, docx (Node.js) | MIT | Выгрузка протокола в PDF и DOCX |
| acad-ts (Node.js), ezdxf | MIT | Чтение DWG/DXF, отрисовка чертежа |
| OpenCV | Apache-2.0 | Распознавание линий на скане чертежа |

Лицензия PyMuPDF требует внимания при поставке в закрытом контуре: возможен
переход на pdfium либо приобретение коммерческой лицензии — это решение уровня
закупки, а не разработки.

## 5. Что проверяется автоматически

- Версии зависимостей закреплены (`packages/ml/requirements.txt`, `package-lock.json`),
  образ сервера модели — по дайджесту.
- Тест `packages/ml/tests/test_llm.py::test_external_address_is_refused_before_sending`: обращение
  к адресу вне контура отклоняется до отправки запроса.

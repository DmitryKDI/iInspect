# Вопросы к заказчику и владельцам смежных систем

Реквизиты внешних интерфейсов не выдумываются. Ниже — то, что требует
уточнения; до получения ответов решение работает в закрытом контуре без
внешних подключений.

## Протокол проверки

1. Шаблон протокола из Приложения № 2 к ТЗ в распоряжении команды не было.
   Протокол собран по тексту ТЗ: пять таблиц, карточки доказательств, версии
   матрицы, модели и набора данных, `input_manifest_hash`. Нужен утверждённый
   образец, чтобы выгрузки DOCX и PDF повторяли его вёрстку.
2. Требуется ли подпись выгружаемого протокола на стороне модуля или её ставит
   внешняя система?

## ИАИС «РиН» — обмен

Входящий комплект принимается автоматически через
`POST /api/v1/documents/upload` по HTTPS: файлы PDF/DOCX/XML, обязательный
машиночитаемый реестр CSV/XLSX/JSON и, для дозагрузки, `process_id`. Для
интеграционной учётной записи предусмотрена роль `service`; OpenAPI-схема
доступна по `/api/v1/openapi.json`.

1. Адрес и формат приёма. Отправка готова и включается переменной
   `INSPECTOR_RIN_URL`: `POST` пакета JSON (версии, реестр входных файлов,
   подтверждённые инспектором нарушения) с заголовком `Idempotency-Key`.
   Если приёмнику нужен другой формат — нужна его спецификация.
2. Аутентификация: модуль предъявляет клиентский сертификат по TLS 1.3
   (`INSPECTOR_RIN_CLIENT_CERT`, `INSPECTOR_RIN_CLIENT_KEY`, `INSPECTOR_RIN_CA`)
   и, при необходимости, токен. Нужны требования к сертификату и к УКЭП.
3. Как внешняя система сообщает о приёме или отказе пакета?
4. Какой способ выдачи сервисной учётной записи и доставки входящих файлов
   утверждён владельцем ИАИС «РиН»?

## Стенд и модель

1. Модель развёрнута локально (vLLM, протокол Chat Completions,
   Qwen2.5-VL-7B-Instruct с открытыми весами). Подтвердить, что лицензия
   модели допустима для использования заказчиком.
2. Стенд (сведения организаторов получены): 1× H100 80 ГБ на команду, GPU
   может быть общим; 24 ядра / 48 потоков; до 640 ГБ ОЗУ; от 300 ГБ диска;
   NVIDIA Container Toolkit, драйвер на хосте. Открыто: сколько памяти GPU
   будет свободно при одновременной работе нескольких команд — от этого
   зависит `INSPECTOR_LLM_GPU_MEMORY`.
3. Требования к журналированию обращений к модели.
